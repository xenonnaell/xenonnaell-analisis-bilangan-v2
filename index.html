📘 About

Bilangan kompleks terdiri dari bagian real dan imajiner, ditulis dalam bentuk:

z = a + bi

  • a adalah bagian real.
  • b adalah koefisien dari bagian imajiner.
  • i adalah satuan imajiner dengan i² = −1.

Website ini mengelompokkan bilangan menjadi empat kategori:

ZEROa = 0 dan b = 0
REALb = 0 dan a ≠ 0
IMAGINARYa = 0 dan b ≠ 0
COMPLEXa ≠ 0 dan b ≠ 0
